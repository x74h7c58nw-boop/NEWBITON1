# SSS급 알바 랭킹

현대 판타지 헌터 시스템을 모티브로 만든 해커톤 시연용 개인 맞춤 알바 추천 웹앱입니다. 특정 작품의 캐릭터나 로고를 사용하지 않습니다.

## 실행

Node.js 20.19 이상 또는 22 이상을 설치한 환경에서:

```sh
npm install
npm run dev
```

터미널에 표시된 로컬 주소로 접속합니다. 프로덕션 빌드는 `npm run build`, 확인은 `npm run preview`, 계산 테스트는 `npm test`입니다.

## 핵심 기능

- 각성 온보딩: 단기/장기, 업무강도, 근무시간, 시급·거리 선호와 헌터 칭호 생성
- 학교·거주 지역·교통수단·가능 요일·시간표 설정 및 localStorage 저장
- 10개 가상 공고의 개인화 POWER와 SSS+~C 등급, 자동 정렬과 카테고리 필터
- 상세 스탯, 추천 이유 및 단점, 찜과 MY 기록
- 두 공고 선택 후 5라운드 배틀, 개인화 POWER 기준 최종 승자
- 왕복 이동시간과 교통비를 반영한 진짜 시급 분석
- 모바일 하단 내비게이션, 키보드 접근 가능한 모달과 시간표

## 계산 원칙

진짜 시급 = (시급 × 근무시간 − 왕복 교통비) ÷ (근무시간 + 편도 이동분 × 2 ÷ 60).

원본 예시에 일부 계산값 불일치가 있어 공식에 맞게 표시합니다. 학교 앞 카페는 13,500원 × 4시간 ÷ 4.2시간 = **12,857원**, 강남 고시급 술집은 (18,000원 × 4시간 − 4,000원) ÷ 6시간 = **11,333원**입니다.

시급·진짜 시급·거리·시간표·교통비·업무강도·계약유형 7개 점수를 0~100으로 정규화하고 사용자별 가중 평균으로 0~9999 POWER를 계산합니다. 등급 경계는 9500/9200/8500/7600/6500/5500입니다. 칭호와 점수 모두 동일한 선호값을 사용하므로 선호도 수정 시 결과가 달라집니다. SSS를 인위적으로 보장하지 않습니다.

시간표 적합도는 공고의 요일·시간과 사용자의 가능 요일·수업의 겹침 및 선호 근무시간을 반영합니다. 학교와 지역은 가상 공고에 기록된 학교·동 이름과 문자열로 비교합니다. 이동수단은 시연용 이동시간 계수를 적용합니다. 실제 지도 경로, 채용 지원, 급여 보장, 실시간 공고 연동은 제공하지 않습니다. 모든 공고와 요금은 mock data입니다.

## 구성

React + Vite + JavaScript, react-router-dom, lucide-react, CSS. 백엔드는 없습니다.

- `src/components/UI.jsx`: 재사용 카드, 등급, 스탯, 모달, 시간표, 내비게이션
- `src/pages/Onboarding.jsx`: 랜딩과 4단계 온보딩
- `src/pages/Board.jsx`: 홈, 랭킹, 상세, MY
- `src/pages/Battle.jsx`: 배틀 진행 및 결과
- `src/data/jobs.js`: 가상 공고
- `src/utils/`: 점수, 진짜 시급, 칭호 생성

브라우저별 localStorage에 설정과 찜·배틀 횟수를 보관합니다. Google Fonts를 사용할 수 없으면 시스템 글꼴로 표시됩니다. 정적 호스팅 시 하위 경로를 index.html로 연결하는 SPA fallback 설정이 필요합니다.

## 3분 시연

1. 각성 시작 → 타입/선호 선택 → 생활 설정 → 수업 몇 칸 선택 후 저장
2. 홈에서 추천 이유와 진짜 시급 확인
3. 강남 고시급 술집과 배틀 시작 → 시급과 실제 보상 차이 확인
4. MY에서 거리·업무강도 선호 수정 → 랭킹 변화 확인

## 유형별 독립 랭킹 (추가)

랭킹 메뉴는 `내 맞춤 랭킹`, `모든 유형별 랭킹`, `안암 실제 공고`로 나뉩니다.

- 장기전의 지배자 / 단기 폭딜 골드헌터 / 고시급 버서커 / 5분컷 장인
- 현생 수호자 / 치고 빠지는 자 / 밸런스 마스터 / 공강 암살자

8개 유형별로 각각 1~10위와 POWER·등급을 계산하고, 내 개인 순위와의 차이를 표시합니다. 각 유형을 누르면 해당 유형 전용 전체 카드 랭킹을 볼 수 있습니다. 카테고리 필터와 추천 이유도 해당 유형 점수를 사용합니다.

학교·지역·이동수단·시간표는 사용자의 현재 생활 설정을 사용하고, 유형마다 대표 선호를 적용합니다. 실제 사용자들의 집계 순위가 아닙니다. 유형별 목록을 살펴봐도 저장된 사용자 선호는 바뀌지 않습니다. 상세 페이지와 배틀은 내 개인 설정 기준입니다.

- 전체 유형: `/ranking?view=types`
- 장기전의 지배자: `/ranking?view=types&type=long`
- 실제 공고 출처: `/ranking?view=anam`

`src/data/hunterTypes.js`가 대표 설정 및 독립 계산을 담당합니다. 균형형 칭호는 업무시간까지 중간값일 때 부여하도록 정리했습니다.
